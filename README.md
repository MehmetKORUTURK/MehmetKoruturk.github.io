# mehmetkoruturk.github.io

Personal website of **Mehmet Koruturk**, M.S. in Electrical Engineering at Virginia Tech.

**Live:** [https://mehmetkoruturk.github.io](https://mehmetkoruturk.github.io)

## Update content

Edit `index.html`, then:

```bash
git add -A
git commit -m "Update content"
git push
```

Changes go live in ~30 seconds.

## Local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
